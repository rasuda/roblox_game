# Game Design — Football Transfer Rivals

O jogo é sobre coleção, roubo, perseguição e progressão — não sobre disputar partidas de futebol.

Loop: treinar → invadir uma zona → roubar contrato → escapar do Guardian/PvP → entrar no clube → assinar → gerar renda → melhorar clube/Speed → alcançar zona melhor.

As quatro zonas ficam visíveis no mesmo mapa: Street Football, Academy, National Club e World Elite. O Speed mínimo cresce de 16 para 44. A renda cresce exponencialmente, mas contratos valiosos aplicam maior penalidade de transporte e Guardians mais rápidos.

Todo conteúdo publicado é fictício.
